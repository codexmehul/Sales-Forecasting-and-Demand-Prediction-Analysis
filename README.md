# Sales Forecasting and Demand Prediction Analysis

An end-to-end data analytics and predictive modeling project designed to analyze historical sales transactions, forecast customer demand, and provide actionable business recommendations for inventory and revenue optimization.

## Project Structure
- **Analysis file/**: SQL queries (`sales_analysis.sql`) and Python time-series demand forecasting models.
- **Cleaned data file/**: Validated and normalized transaction records.
- **Dashboard/**: KPI reporting and visual analytics.
- **Datasets/**: Raw sales data (`raw_sales_data.csv`).
- **Final Insights/**: Executive summary and inventory recommendations.

## Tech Stack
- **Database & Querying:** SQL
- **Data Analysis & Modeling:** Python (Pandas, NumPy, Scikit-Learn)
- **Data Visualization:** Matplotlib, Seaborn
